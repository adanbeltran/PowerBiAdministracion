# Fase 8. Interactividad y navegación

[← Fase anterior](07_FASE_LOGISTICA.md) | [Inicio](00_INICIO.md) | [Siguiente: acción →](09_FASE_ACCION.md)

## Objetivo

Guiar la exploración sin perder el hilo narrativo.

## 1. Navegador de páginas

Cree:

- Inicio.
- Panorama.
- Rentabilidad.
- Logística.
- Acción.

Ruta:

**Insertar → Botones → Navegador → Navegador de páginas**

## 2. Segmentadores sincronizados

Sincronice:

- Región.
- Canal.
- Segmento.

Ruta:

**Vista → Sincronizar segmentadores**

## 3. Marcadores

Cree tres estados:

1. Panorama.
2. Problema.
3. Acción.

Verifique:

- Datos.
- Mostrar.
- Página actual.

## 4. Panel lateral de filtros

Cree dos marcadores:

- Panel abierto.
- Panel cerrado.

Agregue botones para abrir y cerrar.

## 5. Tooltip de página

Incluya:

- Producto.
- Ventas.
- Utilidad.
- Margen.
- Descuento.
- OTIF.
- Minitendencia.

No oculte información esencial en el tooltip.

## 6. Drillthrough

Cree la página `Detalle producto` con:

- Ventas.
- Utilidad.
- Margen.
- Tendencia.
- Pedidos.
- Devoluciones.
- Botón Atrás.

## 7. Drill down y drill up

Jerarquías sugeridas:

- Año → Trimestre → Mes.
- Categoría → Producto.

## 8. Editar interacciones

Revise para cada visual:

- filtrar;
- resaltar;
- ninguna.

## 9. Q&A

Cree una página opcional de exploración libre.

## Error que debe evitarse

Agregar interacciones que no ayudan a responder una pregunta.
