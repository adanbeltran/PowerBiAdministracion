# Fase 7. Logística y nivel de servicio

[← Fase anterior](06_FASE_RENTABILIDAD.md) | [Inicio](00_INICIO.md) | [Siguiente: interactividad →](08_FASE_INTERACTIVIDAD.md)

## Objetivo

Responder:

> ¿Dónde se concentran las entregas tardías y cómo se relacionan con devoluciones y satisfacción?

## Indicadores

- OTIF %.
- Días Promedio de Entrega.
- Tasa de Devolución %.
- Satisfacción Promedio.

## Visual 1. Tendencia temporal

- Eje X: AñoMes.
- Valor: Tasa de Entregas Tardías %.

## Visual 2. OTIF por región

- Barras horizontales.
- Línea de meta.
- Orden ascendente.

## Visual 3. Mapa

- Ubicación: Región.
- Tamaño: Pedidos.
- Color: OTIF %.

El mapa debe complementar, no reemplazar, la comparación de barras.

## Visual 4. Transportadoras

Use matriz o barras con:

- OTIF %;
- Días promedio;
- Devoluciones;
- Satisfacción.

## Visual 5. Cascada descriptiva

Puede representar:

- tiempo base;
- efecto de región;
- efecto de canal;
- efecto de transportadora;
- tiempo final.

No debe presentarse como prueba causal.

## Cierre

Identifique:

- región crítica;
- canal crítico;
- transportadora crítica;
- indicador de seguimiento.

## Error que debe evitarse

Usar un mapa cuando la ubicación no aporta a la decisión.
