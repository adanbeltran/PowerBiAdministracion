# Fase 4. Diseño narrativo

[← Fase anterior](03_FASE_MEDIDAS_DAX.md) | [Inicio](00_INICIO.md) | [Siguiente: panorama →](05_FASE_PANORAMA.md)

## Objetivo

Definir la estructura visual y narrativa antes de construir las páginas.

## Paso 1. Configurar el lienzo

- Formato 16:9.
- Fondo claro.
- Márgenes consistentes.
- Máximo de seis a ocho objetos principales por página.
- Navegación en la misma posición.

## Paso 2. Establecer jerarquía

Cada página debe tener:

1. Título narrativo.
2. Indicadores clave.
3. Evidencia principal.
4. Elementos de exploración.
5. Recomendación o transición.

## Paso 3. Definir el color

- Azul: información general.
- Verde: cumplimiento.
- Rojo o naranja: desviación.
- Gris: contexto.

El color debe resaltar una excepción, no decorar.

## Paso 4. Crear storyboard

| Página | Pregunta | Hallazgo esperado | Acción |
|---|---|---|---|
| Inicio | ¿Qué se analizará? | Contexto | Orientar |
| Panorama | ¿Cómo estamos? | Situación general | Priorizar |
| Rentabilidad | ¿Dónde se pierde valor? | Segmento crítico | Revisar |
| Logística | ¿Dónde se incumple? | Región/canal crítico | Intervenir |
| Acción | ¿Qué hacer? | Plan priorizado | Ejecutar |

## Errores que debe evitarse

- títulos genéricos;
- demasiados colores;
- gráficos sin contexto;
- exceso de filtros;
- recomendaciones vagas.
