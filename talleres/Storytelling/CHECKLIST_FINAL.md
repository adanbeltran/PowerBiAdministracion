# Lista de verificación final

[← Inicio](00_INICIO.md)

## Datos y modelo

- [ ] Los tipos de datos son correctos.
- [ ] Existe una tabla calendario.
- [ ] Las relaciones están activas.
- [ ] Las medidas responden a filtros.
- [ ] Las metas están correctamente relacionadas o consultadas.

## Narrativa

- [ ] La audiencia está definida.
- [ ] Existe una pregunta central.
- [ ] Cada página responde una pregunta.
- [ ] Los títulos comunican hallazgos.
- [ ] La historia termina en una acción.

## Visualizaciones

- [ ] Los gráficos corresponden a la tarea analítica.
- [ ] Las barras están ordenadas.
- [ ] Las metas y líneas base son visibles.
- [ ] Los colores tienen una función.
- [ ] No hay saturación visual.

## Interactividad

- [ ] La navegación funciona.
- [ ] Los marcadores funcionan.
- [ ] Los segmentadores están sincronizados.
- [ ] El tooltip agrega contexto.
- [ ] El drillthrough conserva el contexto.
- [ ] Existe botón Atrás.

## Rigor

- [ ] No se confunde correlación con causalidad.
- [ ] Las conclusiones se pueden verificar.
- [ ] La narración inteligente fue revisada.
- [ ] Las limitaciones están declaradas.
- [ ] La recomendación tiene responsable, indicador y meta.

## Accesibilidad

- [ ] El contraste es suficiente.
- [ ] Los textos son legibles.
- [ ] No se depende únicamente del color.
- [ ] Existe texto alternativo.
- [ ] El orden de tabulación es lógico.
