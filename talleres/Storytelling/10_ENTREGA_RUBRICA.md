# Fase 10. Entrega y rúbrica

[← Fase anterior](09_FASE_ACCION.md) | [Inicio](00_INICIO.md)

## Entregables

1. Archivo `.pbix`.
2. Storyboard inicial.
3. Documento ejecutivo de una página.
4. Capturas de:
   - Panorama.
   - Rentabilidad.
   - Logística.
   - Acción.
5. Sustentación de siete minutos.

## Sustentación

### Minuto 1

Contexto y pregunta.

### Minutos 2 y 3

Panorama.

### Minutos 4 y 5

Diagnóstico.

### Minuto 6

Interactividad.

### Minuto 7

Acción y seguimiento.

## Rúbrica

| Criterio | Peso |
|---|---:|
| Pregunta administrativa | 10 % |
| Calidad y modelado de datos | 10 % |
| Medidas DAX | 15 % |
| Coherencia narrativa | 20 % |
| Selección de visualizaciones | 15 % |
| Interactividad | 15 % |
| Recomendación y seguimiento | 10 % |
| Accesibilidad y presentación | 5 % |
| **Total** | **100 %** |

## Nivel sobresaliente

El informe:

- comunica un mensaje central;
- utiliza evidencia verificable;
- guía la exploración;
- mantiene coherencia entre páginas;
- emplea interactividad con propósito;
- distingue relación y causalidad;
- concluye con una acción medible.
