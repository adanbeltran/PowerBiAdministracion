# Talleres de Electiva Power BI

Material en formato Markdown para estudiantes de **Administración** e **Ingeniería Industrial**. Los talleres siguen una progresión en **Power BI, DAX, SQL, Python y analítica de datos**, con énfasis en interpretación gerencial, control de procesos y toma de decisiones.

## Referencias base del curso

- CRISP-DM: https://www.ibm.com/docs/es/spss-modeler/saas?topic=dm-crisp-help-overview
- Power BI: https://learn.microsoft.com/power-bi/
- Funciones DAX: https://learn.microsoft.com/dax/

## Uso sugerido en clase

1. Desarrollar el trabajo guiado con el profesor.
2. Resolver el reto propuesto en un contexto diferente.
3. Subir siempre el entregable en Moodle según la rúbrica de cada taller.

## Estructura común

Cada taller contiene:

- objetivo del taller,
- marco teórico / conceptual,
- instrucciones de aplicación paso a paso,
- reto en clase: ahora hazlo tú,
- entregables en Moodle,
- rúbrica breve.
